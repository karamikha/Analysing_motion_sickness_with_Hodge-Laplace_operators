# Analysing_motion_sickness_with_Hodge-Laplace_operators
Этот репозиторий содержит код и данные для курсовой работы по теме "Анализ данных о кинетозе путём применения операторов Ходжа-Лапласа".

Важные файлы и директории:
- hodge_laplacians_functions.py - реализованные функции для работы с операторами Ходжа-Лапласа.
- hypotheses/ - директория с .py файлами, в которых содержатся проверки различных гипотез, связанных с операторами Ходжа-Лапласа и их свойствами.
- visualize/ - директория с .py файлами, в которых реализованы различные функции для визуализации данных и частично применены написанные функции.
